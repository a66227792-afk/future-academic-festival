# 도로 위험요소 자동 신고 시스템

미래인재대학 학술제 · 4NOVA 팀 (덕성여자대학교)

도로 사진에서 균열과 포트홀을 인식하고, 파손 면적에 따라 처리 우선순위를 정해 안전신문고에 붙여 넣을 민원문을 만들어 주는 신고 지원 시스템이다. 비전언어모델(HyperCLOVA X, Gemini)의 판정 신뢰성을 300장의 사진으로 평가하였고, 유형별 판정이 더 고른 HyperCLOVA X를 서비스에 연결하였다. VLM의 심각도 판정은 파손 면적과의 상관이 약해 처리 등급에는 사용하지 않는다. 파손 위치와 면적은 YOLOv8m-seg로 구하며, 면적 비율이 2% 미만이면 일반, 2% 이상 5% 미만이면 보통, 5% 이상이면 긴급으로 나눈다. 전체는 Streamlit 웹 앱으로 구현하였다.

## 주요 결과

| 항목 | HyperCLOVA X | Gemini |
| --- | --- | --- |
| 유형 정확도 | 74.9% (응답 295건 기준) | 75.0% |
| 균열 / 포트홀 정확도 | 73.1% / 77.5% | 90.5% / 52.1% |
| 심각도–파손 비율 스피어만 ρ | 0.350 | 0.383 |

YOLOv8m-seg 최종 모델의 마스크 mAP50은 0.714(균열 0.574, 포트홀 0.854)이다.

## 폴더

- `app/` : Streamlit 웹 앱
- `vlm_eval/` : VLM 평가 코드
- `area/` : 파손 면적 비율 계산
- `yolo/` : YOLOv8-seg 학습과 검증
- `results/` : 평가 결과와 최종 표·그래프

## 실행

```bash
pip install -r app/requirements.txt
streamlit run app/app.py
```

위치 검출에는 학습한 가중치 파일(`best.pt`)이 필요하다. 용량 때문에 저장소에는 넣지 않았으며, [Releases](../../releases)에서 `best.zip`을 내려받아 압축을 풀고 `best.pt`를 `app/app.py`와 같은 폴더에 두면 자동으로 사용된다. 가중치가 없으면 임시 값으로 화면 흐름만 확인할 수 있다.

HyperCLOVA X API 키는 앱 화면에서 입력한다. 키가 없으면 인식 결과는 가짜 데이터로, 민원문은 기본 문장 틀로 만들어진다.
